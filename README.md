# kanablade · 禅

Дзен-тренажёр набора японского текста. Фраза появляется как в караоке. Её набирают ромадзи по буквам, и каждый слог загорается золотом и звучит нотой.

```sh
cargo run --release                 # встроенные фразы (50 штук: хайку, пословицы, обиходные)
cargo run --release -- my.txt       # свои фразы
cargo run --release -- --no-vsync   # минимальная задержка ценой разрывов кадра
```

## Установка

Сборки для всех систем лежат в [Releases](https://github.com/brennschlus/kanablade/releases) (для тега `v*`) и в артефактах каждого прогона Actions.

- **macOS** (`.dmg`, universal: Apple Silicon и Intel): перетащить kanablade в «Программы». Сборка не нотаризована,
  поэтому первый запуск через правый клик → «Открыть».
- **Windows** (`.zip`): один `kanablade.exe` с иконкой и описанием в свойствах файла, без консольного окна.
- **Linux** (`.tar.gz`, x86_64 и aarch64, glibc ≥ 2.35): `./install.sh` кладёт программу в `~/.local`
  вместе с ярлыком в меню и иконками (`PREFIX=/usr/local` для всей системы, `--uninstall` для удаления).
  Бинарник из `bin/` работает и без установки.

Собрать пакет локально: `packaging/linux/package.sh`, `packaging/macos/package.sh`, `packaging/windows/package.ps1`, результат в `dist/`.
Иконки генерирует `packaging/icons/render.py` (нужен Pillow).

## Управление

| Клавиша | Действие |
|---|---|
| a–z, `-`, `'` | набор (по физической клавише, работает и в русской раскладке) |
| Tab | ромадзи: вся фраза → только слог → скрыто (появляется при ошибке или паузе) |
| F2 | перевод |
| F3 | звук |
| Enter | следующая фраза |
| F11 | полный экран |
| Esc | выход |

Принимаются все распространённые варианты: `shi/si`, `tsu/tu`, `chi/ti`, `fu/hu`, `ji/zi`, `ja/zya/jya`, `kixya`;
`っ` через удвоение согласной (`ippo`, `matcha`/`maccha`) или `xtu`/`ltu`; `ん` как `n` (перед согласной), `nn`, `n'`, `xn`.

## Свои тексты

Одна фраза на строку, чтение кандзи в квадратных скобках сразу после них, перевод после `|`:

```
古池[ふるいけ]や蛙[かわず]飛[と]び込[こ]む水[みず]の音[おと] | Старый пруд…
コーヒーを飲[の]みましょう | Давай выпьем кофе.
# строки с решёткой пропускаются
```

Знаки препинания (、。！) набирать не нужно.

## Устройство

- **Bevy 0.20**: текст через parley/swash, HDR и bloom для свечения. Каждый глиф отдельная сущность, поэтому у каждого своя анимация.
- **Отзывчивость**: конвейерный рендер выключен, `desired_maximum_frame_latency = 1`, ввод обрабатывается в том же кадре, что и отрисовка.
  Следующая фраза заранее отрисована внизу экрана, так что глифы уже в атласе и при смене строки нет подтормаживаний.
- **Звук**: kira 0.12 на отдельном потоке, буфер cpal 512 сэмплов (~10 мс). Все звуки синтезируются при запуске:
  щелчок клавиши, «кото» в ладу Ин (гласная слога задаёт ноту), мягкий звук ошибки, поющая чаша в конце фразы, эмбиент. Ноты и чаша идут через реверб.
- **Шрифты**: Zen Old Mincho и Zen Maru Gothic (SIL OFL, `assets/fonts/OFL-ZenFonts.txt`), встроены в бинарник.

```
src/kana.rs    движок ромадзи → кана (с тестами)
src/corpus.rs  разбор фуриганы, встроенные фразы
src/audio.rs   синтез и воспроизведение
src/scene.rs   сцена, ввод, анимации
src/demo.rs    KANABLADE_DEMO=<dir>: автонабор и скриншоты для проверки
build.rs       иконка и сведения о версии в .exe (Windows)
packaging/     иконки, .desktop и metainfo, Info.plist, скрипты сборки пакетов
```
